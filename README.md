# game2

> Emoji vs 幽灵 生存小游戏（PWA）

<p><img src="https://img.shields.io/badge/lang-HTML-blue?style=flat-square"/></p>

## 简介
一个以 Emoji 表情与幽灵为主题的网页生存小游戏，打包为 PWA（含 manifest.json 与 Service Worker），可安装到桌面并离线游玩。

## 技术栈
HTML5 / JavaScript（Webpack 打包）+ PWA（Service Worker / manifest）

## 快速开始
无需本地构建，用浏览器打开 `index.html` 即可游玩；支持通过浏览器「安装」为 PWA 离线使用。
